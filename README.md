# Stillglass

Zoom a picture, lift the light, and trace where else it appears.

## Install

1. Download this repository as a zip (Code, then Download ZIP) and unzip it.
2. Open the folder that contains `manifest.json` directly inside it. If GitHub named it `stillglass-main`, use that folder.
3. Open `chrome://extensions`.
4. Turn on **Developer mode** (top right).
5. Choose **Load unpacked** and select that folder.
6. Reload any tab that was already open.

## Use it

- Hover a large photo and click **Loupe**.
- Drag the picture, then scroll to zoom that spot.
- Right-click a photo and choose Stillglass, then an engine: Google Lens, TinEye, Yandex, or Bing.
- Press **Alt+Shift+L** for the loupe, **Alt+Shift+F** to grab a video frame.
- If a player won't share its frames, Stillglass photographs the visible page instead. Trace that still.
- The toolbar button can capture the page, grab a frame, or hide the hover chip.

Pictures are sent to a search engine only when you ask. Stillglass does not upload them anywhere else.

Tuning (brightness, contrast, color, warmth, rotate, flip) stays on your screen. A trace uses the original picture, not the tuned preview.
